# 01 — Scripting

Script first. No animation, no template, no voiceover timing until the script exists.

## Reel script format (25–32 seconds, Hinglish)

A reel has one idea and one CTA. The proven shape is:

1. **Hook (first 2–3 seconds)** — the pain or the promise, in one line.
   - Bad: "Aaj main aapko ek AI tool ke baare mein bataunga."
   - Good: "Ek kaam jo 60 minute leta tha, ab 10 minute mein ho jayega."
2. **3 numbered steps** — each step is one action, one line, in order. Number them on screen.
   - Step 1: what to do first.
   - Step 2: what to set / tell the AI (tone, brief, format).
   - Step 3: what to check or finish yourself.
3. **Tip (one line)** — the mistake to avoid. Example: "Blindly copy-paste mat karo, apne style mein edit karo."
4. **CTA (last 2–3 seconds)** — comment the keyword to get the guide/link by DM.
   - Example: "Comment karo FAST, aur poora setup DM mein bhej dunga."

Rules:
- Spoken script and on-screen captions must match. Captions are not a summary; they are the script, word by word.
- Keep each on-screen line to 2–3 short lines maximum. If a sentence is long, split it across caption chunks, not across tiny text.
- No tool name or website link in the video unless the user supplied it. If the user supplies a link later, it goes in the DM reply text, and the video is not silently changed.
- If the user supplies their own script, keep it as written, including Devanagari if supplied in Devanagari.

## Long-video script format (sample ~1 minute, full ~10 minutes)

1. **Hook** — a real, relatable opening scene or question. No invented victim, name, or loss figure.
2. **How it works** — the mechanism, explained simply, in order.
3. **Why it works** — the psychology / reason, in plain language.
4. **Red flags** — a numbered list the viewer can actually check.
5. **What to do in the moment** — exact, calm steps.
6. **Protection plan** — a simple family / personal rule the viewer can set up today.
7. **What NOT to do** — the common mistakes, stated clearly.
8. **Closing** — one takeaway line + one action.

For a 1-minute sample, compress this to 5 scenes: Hook, How It Works, Red Flags, Verify, Lesson.
For a full video, expand to 8–12 scenes, each roughly 45–55 seconds of spoken audio, and keep the same order.

Rules:
- One topic, one promise. Do not mix two topics in one video.
- Prevention / awareness topics stay prevention-only. Explain how to recognise and stop it, never how to do it.
- If TTS returns empty audio for a line, soften that one line's wording and re-record it. Do not drop the scene, and do not invent a different claim to fill the gap.

## Voiceover timing

- The voiceover audio is the timeline. Scene boundaries come from the real audio seconds, not from guessed timings.
- If the user supplies audio, measure its real duration first, then map scenes to real audio seconds.
- Caption timing follows the spoken words. Where speech is continuous (for example, a list spoken without pauses), space the caption highlights evenly across that list's audio window and say so honestly — do not claim exact per-word timestamps you do not have.
