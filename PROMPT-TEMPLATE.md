# Prompt template — the shortest brief that works

Copy this, fill the blanks, and send it to Muse along with this repo link. You do not need to explain the process — this repo already does that.

---

Muse, is repo ke hisaab se video banao:

- **Topic:** ________
- **Video type:** Reel / Long video (sample / full)
- **Length (agar long video hai):** ________
- **Audio language (boli hui voiceover ki language):** ________
- **Subtitle language (karaoke caption ki language / script — Roman Hinglish, Devanagari Hindi, English):** ________
- **Video language (on-screen headings, cards, labels ki language):** ________
- **CTA keyword (agar reel hai):** ________
- **Voiceover:** AI voiceover / Meri supplied audio file
- **Style (optional — khaali chhodo to tum choose karo):** ________
- **Kuch khaas jo dhyaan rakhna hai:** ________

Pehle script dikhao, phir video banao. Publish karne se pehle exact video, caption aur account dikhakar approval lo.

---

## If you only have a topic

Just send this:

> Muse, is repo ke hisaab se [TOPIC] par ek reel banao.

Muse will NOT assume the rest and start. It will ask you one question at a time — first video type, then audio language, then subtitle language, then video language, then CTA and voiceover — waiting for each answer, and only then start with the script.
